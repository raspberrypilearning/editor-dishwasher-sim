# Dishwasher simulator

![Dishwasher simulator](banner.png)

Make a dishwashing game in this Code Club arcade project.

This Raspberry Pi Code Editor tutorial has a landing page and 29 short steps, with one or two build tasks per step and a final challenge.

## Project files

- Start at [en/landing.md](en/landing.md).
- Step order and completion markers are defined in [en/meta.yml](en/meta.yml).
- Starter and completed Scratch projects are in [en/code](en/code).
- Supporting materials are in [en/resources](en/resources).
- The completed learner solution is in [en/solutions](en/solutions).

Find the project online at [projects.raspberrypi.org/en/projects/editor-dishwasher-sim](https://projects.raspberrypi.org/en/projects/editor-dishwasher-sim).
